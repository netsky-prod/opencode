# Next milestone: peer swarm

Requested after completion, verification, installation, and integration of the capability-packs milestone.

## User requirements

- Swarm-driven work: all agents solve the same task concurrently and coordinate with one another.
- Shared task context across the agents.
- Peer coordination, not a supervisor assigning work down a subagent hierarchy.

This records the next milestone, not an approved implementation design. Its context consistency, coordination, concurrent changes, and verification semantics will be designed after the current milestone is closed. No swarm implementation is included in capability-pack acceptance.
