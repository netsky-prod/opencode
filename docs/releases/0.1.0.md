# Netsky Code 0.1.0

The first release under the Netsky Code name: an independently maintained, open-source agent harness built on OpenCode.

## Included

- Launch with `netsky`; new Netsky Code terminal and web identity.
- A native `/capabilities` manager for session-scoped packs and MCP connections.
- Add local/remote MCP servers, select project/global storage, inspect connection health, and attach existing connections to a pack without putting credentials in pack manifests.
- Browser, research, mobile, security tooling, documents/media, GitHub and deploy capability packs.
- Durable `/loop` continuation and evidence checkpoints.
- The thinking-stream event duplication fix from our previous local build.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/netsky-prod/opencode/dev/install | bash
netsky --version
netsky
```

Existing OpenCode-compatible configuration, session history and credentials remain supported. Use `netsky -c` to continue your latest session. Internal package namespaces, data paths and `OPENCODE_*` variables remain compatible in this release.

## Assets

Unsigned CLI binaries for macOS arm64/x64 and glibc Linux arm64/x64 (AVX2 required on x64 Linux). Each archive contains `netsky`; the web UI is embedded. Verify downloads against `SHA256SUMS` and inspect `release.json` for platform and hash metadata. No npm, Homebrew, signed desktop, Windows or mobile binaries are published by this release.

External models, MCP services and pack dependencies are configured separately. LangGraph Swarm, peer-swarm and Hugging Face Agent Collabs are not shipped in this version.
