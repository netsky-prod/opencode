# Netsky Code

This project is now distributed as **Netsky Code**, launched with `netsky`.

The maintained installation and usage guides are available in [English](README.md) and [Русский](README.ru.md). This language's inherited OpenCode guide has been retired to avoid directing users to a different product's packages and releases.

Netsky Code is independently maintained, based on [OpenCode](https://github.com/anomalyco/opencode), and distributed under the [MIT license](LICENSE).
